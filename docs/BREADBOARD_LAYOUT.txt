   ⚠  CRITICAL: VOLTAGE DIVIDER on R307 → ESP32 RX line

        R307 TX ────┬──── 1 kΩ ────┬──── GPIO 16 (RX2)
                    │              │
                    │           ┌──┴──┐
                    │           │2 kΩ │  (or 1.8 kΩ, anything 1k–2.2k)
                    │           └─┬──┘
                    │             │
                    └─────────────┴────────── GND

   The R307 UART line is 5V. ESP32 GPIO is 3.3V only.
   The divider drops 5V → ~3.3V at the GPIO pin.
   Other direction (ESP32 TX → R307 RX) is fine, both are 3.3V CMOS logic.
